** Fonts
=install.sh= installs these on macOS; on Debian/Ubuntu use
=sudo apt install fonts-cantarell fonts-firacode=.

Two things this has to work around:

1. A missing font does *not* signal an error — Emacs silently falls back to some
   default. So a typo or an uninstalled family is invisible except that the frame
   looks wrong. =skls/first-font= makes the choice explicit and returns nil when
   nothing matches, so the =when-let= simply leaves the face alone.
2. =font-family-list= returns nil when there is no GUI frame, which is the case
   during init under =--bg-daemon=. Applying fonts only at load time would leave
   a daemon's frames unstyled, so =skls/apply-fonts= also runs from
   =after-make-frame-functions=.

#+begin_src emacs-lisp
  (defun skls/first-font (&rest families)
    "Return the first family in FAMILIES available in the current frame, else nil.
  Returns nil when there is no graphical frame, since `font-family-list' is
  empty then and no font choice can be validated."
    (when (display-graphic-p)
      (seq-find (lambda (family) (member family (font-family-list))) families)))

  (defun skls/apply-fonts (&optional _frame)
    "Set the default and variable-pitch faces, if the fonts exist."
    (when-let ((mono (skls/first-font "Fira Code" "FiraCode Nerd Font"
                                     "MesloLGS NF" "Menlo" "DejaVu Sans Mono")))
      (set-face-attribute 'default nil :font mono :height 110))
    (when-let ((sans (skls/first-font "Cantarell" "Helvetica Neue" "DejaVu Sans")))
      (set-face-attribute 'variable-pitch nil :font sans)))

  ;; Once now (normal startup) and once per new frame (daemon startup).
  (add-hook 'after-make-frame-functions #'skls/apply-fonts)
  (skls/apply-fonts)
#+end_src

** Window Jump
=general-define-key= with =:keymaps 'override= gives these precedence over major
modes, which is what the previous hand-rolled =my-keys-minor-mode= (plus its
=minibuffer-setup-hook= workaround to switch itself off) existed to achieve.
=general= is already a dependency, so this drops ~15 lines and a stray modeline
lighter.

Wrapped in =with-eval-after-load= rather than called at top level, so it does not
depend on =general= having loaded by the time this section is evaluated.

#+begin_src emacs-lisp
  (with-eval-after-load 'general
    (general-define-key
     :keymaps 'override
     "<M-C-up>"    'windmove-up
     "<M-C-right>" 'windmove-right
     "<M-C-down>"  'windmove-down
     "<M-C-left>"  'windmove-left))
#+end_src
