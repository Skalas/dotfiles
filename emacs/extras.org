** Markdown
Rendered via =pandoc= (=multimarkdown= was never installed, so preview silently failed).
=markdown-hide-markup= mirrors the org-appear behaviour — toggle with =C-c C-x C-m=.
#+BEGIN_SRC emacs-lisp
  (use-package markdown-mode
    :commands (markdown-mode gfm-mode)
    :mode (("README\\.md\\'" . gfm-mode)
           ("\\.md\\'" . markdown-mode)
           ("\\.markdown\\'" . markdown-mode)
           ("\\.mdx\\'" . markdown-mode))
    :custom
    (markdown-command "pandoc -f gfm -t html5 --standalone")
    (markdown-fontify-code-blocks-natively t)
    (markdown-hide-markup t)
    (markdown-header-scaling t))
#+END_SRC

*** grip-mode
Live GFM preview through GitHub's own renderer, so task lists, alert blockquotes and
mermaid blocks match what GitHub shows. Bound to =C-c C-c g=. Needs =grip= on PATH
(installed by =install.sh=) and a =GITHUB_TOKEN= in =~/.zshrc.local= to avoid the
unauthenticated API rate limit. Previews in an xwidget buffer — this emacs-plus build
has WebKit support.
#+BEGIN_SRC emacs-lisp
  (use-package grip-mode
    :after markdown-mode
    :bind (:map markdown-mode-command-map
                ("g" . grip-mode))
    :custom
    (grip-preview-in-webkit t)
    (grip-real-time-refresh t))
#+END_SRC

    :commands (gptel gptel-send gptel-menu)

** Claude Code
Run Claude Code CLI inside Emacs via Vertex AI. Requires the ~claude~ CLI to be installed.
#+begin_src emacs-lisp
  ;; Vertex AI environment for Claude Code
  (use-package inheritenv
    :straight (:host github :repo "purcell/inheritenv"))

  (use-package claude-code
    :straight (:host github :repo "stevemolitor/claude-code.el"
               :branch "main" :depth 1)
    :bind-keymap ("C-c c" . claude-code-command-map)
    :config
    (setq claude-code-terminal-backend 'vterm)
    (claude-code-mode))
#+end_src
